# melishekan

آخرین فایل NV کانال `@sinavm` اینجا می‌نشیند.

مسیر:
1. پست جدید NV در کانال
2. ریپو `sinavm/sinavm` فایل را به `media/nv-latest-1.npvs` می‌برد
3. این ریپو همان فایل را جایگزین می‌کند
